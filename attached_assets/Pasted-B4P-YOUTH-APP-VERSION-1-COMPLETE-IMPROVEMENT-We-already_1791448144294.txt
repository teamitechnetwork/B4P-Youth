3. AUTHENTICATION PROTECTION
==================================================

If a user is NOT logged in and tries to access:

/dashboard
/opportunities
/programs
/events
/profile
/notifications

redirect them to:

/login

If an ADMIN is not logged in and tries to access any admin route:

/admin/*
redirect to Admin Login.

If a normal USER tries to access:

/admin

Do not allow access.

Show an access denied message or redirect them to their Youth Dashboard.

If an authenticated user opens "/" again:

USER:
→ Youth Dashboard

ADMIN:
→ Admin Dashboard

Keep users securely logged in between app sessions unless they log out or their session expires.

Include a clear Logout function.
